# Support

## Getting help

1. Read README.md, CONTRIBUTING.md, and docs/operations/
2. Search existing issues
3. Open a bug report or feature request using the issue templates

## Security issues

Do not open public issues for vulnerabilities. Follow SECURITY.md.

## Self-hosted CI

If runners are offline, see docs/operations/self-hosted-runners.md and run `pnpm runner:check` on the runner host.

## Response expectations

This repository is maintained on a best-effort basis. Provide reproduction steps and command output for the fastest response.
