# ADR: Design-token strategy

- **Status:** Accepted
- **Date:** 2026-07-29

## Context

UI must stay coherent across agents without hardcoded one-offs.

## Decision

CSS variables in tokens.css + DESIGN.md as authority; Tailwind maps to semantic tokens.

## Consequences

Themeable light/dark and reviewable design language.

## Alternatives considered

Utility-only Tailwind with no tokens
