# ADR: pnpm

- **Status:** Accepted
- **Date:** 2026-07-29

## Context

Need deterministic installs and strict dependency isolation for a SaaS foundation.

## Decision

Standardize on pnpm with pinned packageManager and frozen lockfile in CI.

## Consequences

Faster installs, stricter node_modules layout, workspace-ready later.

## Alternatives considered

npm, yarn, bun
